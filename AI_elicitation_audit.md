# AI Elicitation Audit

#### What the Model Missed

The model missed asking how users would enter and manage their wishlist items.
For example, Claude did not ask what information should be required when adding an
item. Claude also did not ask what features I wanted to keep out of the first version of the app.


#### What AI Invented

Claude ended up inventing a variety of things, such as user authentication/email/password,
social login, product URLs, and guest mode. These features were not part of my original
requirements and would make the application more complex than I intended.


#### Useful Requirements the AI Identified

Claude suggested sorting items by price, date added, or priority, which could make it
easier for users to organize their wishlist. This is something useful that I never
thought of for the web app.


#### Overall Judgment

My final judgment was that Claude did give a lot of things to add to the web app, but
the web app will not be created to be overcomplicated. The suggestions are actually
great, and I believe if it were to be a formal app that the general public would use
daily, these requirements could be useful. However, for the amount of time given for
the project, these features would have to be added later to further improve the website.
