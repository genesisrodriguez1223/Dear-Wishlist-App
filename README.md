# Dear Wishlist App
My individual project for 4081..
''Dear Wishlist'' is a wishlist app made to help users organize and keep track of items they would want to purchase. Users will be able to add items they would like to buy with information such as the item name, price, store, category, and priority level. The users will also be able to edit or remove items, mark items as purchased, and view the estimated total cost of their wishlist. This app is useful for users who want a visually organized way to keep track of items they are interested in buying.

## Stack being used
Python .. main programming language
Flask .. Turns program into web app
HTML .. creates the headings, buttons, (content) 
CSS .. makes the app with color 
SQLite .. Saves items even if app is closed
pytest .. tests code
pip .. installs packages
GitHub ..stores files
