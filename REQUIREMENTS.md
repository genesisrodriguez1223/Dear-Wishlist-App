# Requirements for Dear Wishlist
## User Story 1 - Adding an Item
Users want to be able to add an item to their wishlist to keep track of things to buy.
### Acceptance Criteria
- The user can enter an item name.
- The user can enter a price.
- The user can enter a store.
- The user can select a priority.
- The item is saved to the wishlist.
## User story 2 - View Wishlist
Users want to be able to view their entire wishlist.
### Acceptance Criteria
- The wishlist displays all saved items.
- Each item displays its name, price, store, and priority.
- The wishlist shows whether an item has been bought
## User story 3 - Edit an Item
Users want to be able to edit an item such as the information ( price, store ..) if something were to change.
### Acceptance Criteria
- The user can select an existing item to edit.
- The user can change the item's price.
- The user can change the item's store.
- The updated information is saved to the wishlist.
## User story 4 - Delete an item
Users want to be able to delete an item off their wishlist.
### Acceptance Criteria
- The user can select an item to delete.
- The selected item is removed from the wishlist.
- The deleted item no longer appears on the wishlist.
## User story 5 - Mark an item as bought
Users want to be able to mark an item as already bought so they can mark it off their wishlist.
### Acceptance Criteria
- The user can select an item to mark as bought
- The selected item is is shown as bought on wishlist
## User story 6 - Search/filter items
Users want to be able to see certain items so filter the search and to easily find certain items.
### Acceptance Criteria
- The user can filter items by priority.
- The user can filter items by whether they are bought or not bought.
- Only items that match the selected filter are displayed.

## Non-Functional Requirements

### Non-Functional Requirement 1 - Performance

The wishlist page should load within 2 seconds when it contains 100 or less items.

### Non-Functional Requirement 2 - Reliability

Items saved to the wishlist should remain saved after the user closes and reopens the app.

## Non-Functional Requirement 3 - Compability

The application should work correctly on both Google Chrome and Safari.
